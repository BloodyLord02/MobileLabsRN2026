# Лабораторна робота 3
Для запуску застосунку npx expo start
## На головному екрані реалізовано:
1. відображення поточної кількості очок (лічильник);
2. інтерактивний об’єкт (зображення кота), який реагує на дії користувача;
3. інформаційний блок із поясненням жестів;
4. навігаційний блок для переходу до інших екранів.
## Реалізовані наступні жести:
1. TapGestureHandler — коротке натискання додає 1 очко;
2. Double Tap — подвійне натискання додає 2 очки;
3. LongPressGestureHandler — довге натискання додає 5 очок;
4. FlingGestureHandler (свайп) — свайп вліво або вправо додає випадкову кількість очок;
5. PanGestureHandler — перетягування об’єкта (фіксується як виконане завдання);
6. PinchGestureHandler — масштабування додає 3 очки.
