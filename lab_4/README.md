# Лабораторна робота 4
Для запуску застосунку npx expo start
## Опис реалізованого функціоналу:
У застосунку реалізована навігація по локальній файловій системі додатку.
Користувач може:

переглядати поточний шлях до відкритої директорії;

переглядати список файлів та папок;

переходити у вкладені папки;

повертатися до попередньої директорії за допомогою кнопки «Назад».
Для відображення вмісту директорії використовується компонент FlatList.

![СвГоловнийЄкран](https://github.com/BloodyLord02/MobileLabsRN2026/blob/main/lab_4/7.jpg)

## Створення папок
Реалізовано створення нових папок.
Користувач вводить назву папки у поле введення, після чого папка створюється у поточній директорії.
Для створення використовується метод:FileSystem.makeDirectoryAsync()

![СвГоловнийЄкран](https://github.com/BloodyLord02/MobileLabsRN2026/blob/main/lab_4/6.jpg)

## Створення текстових файлів
Реалізовано створення текстових файлів формату .txt.
Користувач може:

ввести назву файлу;

ввести початковий текст файлу;

створити файл у поточній директорії.

Для запису файлів використовується: FileSystem.writeAsStringAsync()

![СвГоловнийЄкран](https://github.com/BloodyLord02/MobileLabsRN2026/blob/main/lab_4/5.jpg)

## Перегляд вмісту файлів
Користувач може відкривати текстові файли та переглядати їхній вміст.

При натисканні на файл:
файл зчитується;
відкривається модальне вікно редактора.

Для читання використовується: FileSystem.readAsStringAsync()

![СвГоловнийЄкран](https://github.com/BloodyLord02/MobileLabsRN2026/blob/main/lab_4/4.jpg)

## Редагування файлів

У застосунку реалізовано редагування текстових файлів.

Користувач може:

змінювати текст файлу;

зберігати внесені зміни.

Після збереження новий вміст записується у файл.

![СвГоловнийЄкран](https://github.com/BloodyLord02/MobileLabsRN2026/blob/main/lab_4/3.jpg)

## Видалення файлів та папок

Реалізовано видалення файлів і директорій.

Перед видаленням відображається підтвердження дії через Alert.

Для видалення використовується:FileSystem.deleteAsync()

![СвГоловнийЄкран](https://github.com/BloodyLord02/MobileLabsRN2026/blob/main/lab_4/1.jpg)

## Висновки
Опанував механізми роботи з локальною файловою системою
мобільного пристрою, використовуючи можливості бібліотеки expofile-system. Закріпив навички реалізації базових операцій над
файлами й папками, організації файлової навігації та аналізу стану
файлової системи.
